Project Details

A collaborative iOS mobile app built with Swift and SwiftUI that helps users discover fun, personalized date ideas. The app features an interactive spin‑the‑wheel date generator, an archive system for saving past dates, and a fully integrated AI chatbot powered by OpenAI for personalized suggestions. You contributed heavily to the frontend UI, feature logic, and Firebase backend, while your partner handled Google Sign‑In and MapKit restaurant finder.

My Roles & Responsibilities

  • Spin‑the‑wheel feature — designed and implemented the interactive date wheel with animations and dynamic logic
  • Archive system — built the saved‑dates feature, including UI, storage logic, and retrieval
  • AI chatbot integration — connected OpenAI API and built the UI/UX for personalized date suggestions
  • Firebase backend work — implemented database structure, data syncing, and core authentication flows
  • Frontend development — built major UI screens, animations, transitions, and interactive components
  • State management — handled dynamic UI updates using SwiftUI’s reactive system
  • App architecture — structured views, models, and view models for clean, maintainable code
  • Testing & debugging — ensured stable feature behavior, smooth UI rendering, and reliable API calls

Technologies

  • Swift — core language for iOS development
  • SwiftUI — declarative UI framework for building interactive screens
  • Firebase — backend for authentication, database, and cloud storage
  • Google Sign‑In — secure user login and identity management
  • MapKit — location‑based restaurant and date spot discovery
  • OpenAI API — chatbot integration for personalized date suggestions
  • Xcode — development environment for building and testing the app
  • Swift Concurrency — async/await for smooth API calls
  • MVC Architecture — clean separation of UI and logic
